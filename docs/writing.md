# WeFlow 写作与保存

使用 Markdown 写文章，右侧预览排版。新建文章默认使用「简洁技术」，不会带入上一篇的主题和自定义 CSS；旧文章按保存的主题恢复。二级标题使用黑底白字，章节编号手动填写。代码块自动显示行号，代码可横向滚动。

浏览器存储无需选择目录，编辑后自动保存。请勿清除站点数据，可定期导出 Markdown 备份。本地文件夹模式在 Chrome / Edge 的 localhost 或 HTTPS 页面可用，选择目录并授权后，文章以 Markdown 文件保存；重新打开时可能需要再次授权。

「复制到公众号」生成带主题的富文本，粘贴到公众号后台后应保存草稿并重新打开检查图片和排版。「复制 HTML」提供语义 HTML，不包含主题装饰与代码行号。本地文件夹中的 Markdown 文件保留可继续编辑的原文及现有文件元数据；PNG 长图按手机宽度折行。

```js
// 代码块保留缩进与空行
const message = "Hello, WeFlow";

console.log(message);
```
